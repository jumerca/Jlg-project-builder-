# TV Network Tycoon Studio Edition V1.3

Hébergement statique gratuit par Render. Le dossier `tv-network-tycoon` est le répertoire de publication.

Cette branche indépendante préserve le code du jeu V1.2 tout en appliquant une nouvelle identité et une refonte graphique.

## Anciennes carrières

Une nouvelle origine web ne partage pas les données stockées dans le navigateur de l'ancien site AppDeploy. Ouvre l'ancienne application, exporte ta carrière JSON depuis son menu, puis importe-la sur le nouvel hébergement.

## Publication

Branche : `tv-network-tycoon-studio`, `buildCommand`: `echo "Static build ready"`, `publishPath`: `tv-network-tycoon`.
