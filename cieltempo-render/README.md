# CielTempo — JLG Creative

Version indépendante de Vercel, hébergée sur Render Static Site depuis la branche dédiée `cieltempo-render-v3` du dépôt `jumerca/Jlg-project-builder-`.

Les seuls fichiers publiés par Render sont ceux du répertoire `cieltempo-render/` de cette branche. Le dépôt commun et les autres branches ne sont pas modifiés.

Fonctions : radar RainViewer, vraie cartographie prévisionnelle WeatherAPI sans interpolation, lecture animée, 48 prévisions horaires avec icônes (Open-Meteo ou MET Norway), GPS et recherche géographique. Toutes les sources nécessitent Internet et peuvent connaître des indisponibilités. Les images de prévisions ne sont pas des cartes officielles AROME.

PWA : installer depuis le navigateur Android (menu « Installer l'application ») et conserver le même HTTPS. Mises à jour : modifier cette branche puis Render redéploie automatiquement.
