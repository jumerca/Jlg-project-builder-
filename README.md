# JLG Project Builder

PWA mobile-first autonome pour piloter des projets créatifs et numériques.

## V1
- Dashboard multi-projets
- Création guidée selon le type de projet
- Brief dynamique
- Checklist des éléments à récupérer au client
- Étapes, Kanban et tâches
- Livrables
- Versions et retours client
- Validations
- Budget
- Notes + dictée vocale si le navigateur la permet
- Agenda global
- Clôture de projet
- Export / import JSON
- PWA installable et fonctionnement hors-ligne après première ouverture

## Données
Les données sont stockées localement sur l'appareil. Utiliser l'export JSON pour sauvegarder ou changer d'appareil.

## Hébergement
Application statique : publier le contenu du dossier sur GitHub Pages ou tout hébergeur HTTPS statique.
